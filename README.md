# Micronutrient Deficiency Diagnostic Matrix

An advanced, interactive structural logic engine designed for portfolio presentation. This client-side web application simulates a comprehensive clinical mapping protocol that evaluates multiple overlapping user parameters to provide personalized nutritional and dietary routing strategies.

🌐 **Live Demo:** [https://Sasipranvithaa.github.io/vitamindeficiency-detector-/](https://Sasipranvithaa.github.io/vitamindeficiency-detector-/)

---

## 🚀 Key Features & Architectural Matrix

### 📊 1. Multi-Layered Condition Matrix
The analytical core processes inputs beyond basic symptom checking by introducing dynamic routing variables:
* **Target Age Cohorts:** Dedicated evaluation routing logic for **Children (0–14)**, **Adults (15–64)**, and **Seniors (65+)**.
* **Symptom Severity Vectors:** Distinct system handling profiles for **Normal/Mild**, **Rare/Sporadic**, and **Acute/Severe** instances.

### 🥗 2. Bifurcated Food vs. Supplement Routing
Rather than displaying a generic text block, the diagnostic engine splits its management suggestions into two separate visual compartments inside every result card:
* **Recommended Food Architecture:** Highly accurate, precise dietary guidelines optimized instantly based on Step 1 selections (**Standard**, **Vegetarian**, or **Strict Vegan** profiles).
* **Targeted Supplement Context:** Displays over-the-counter clinical supplement pathways (e.g., *Methylcobalamin*, *Cholecalciferol*) and safely frames heavy-dosage contexts.

### 🚨 3. Smart Contextual Advice Banners
The matrix includes a conditional rule module that evaluates intersecting data points to dynamically change safety components and output distinct colored banners:

| Evaluated Parameters | UI Visual Indicator | Dynamic Logic Output |
| :--- | :--- | :--- |
| **Severity: Acute / Severe** | 🔴 Critical Red Alert | Immediately commands the user to halt testing and consult a certified medical doctor for clinical blood diagnostics. |
| **Age: Child (0–14)** | 🟡 Pediatric Warning | Displays a strict advocacy directive emphasizing that growing children must secure pediatrician-guided optimization. |
| **Statistical Prevalent Matches** | 🔵 Population Trend Info | Automatically flags if a specific demographic group is historically vulnerable to that exact nutrient gap (e.g., B12 for Seniors). |
| **Severity: Rare / Sporadic** | 🔵 Maintenance Insight | Advises the user to focus strictly on balancing general food logging habits since symptoms are inconsistent. |

### 📱 4. Completely Mobile-Optimized Interface
* **Adaptive Layouts:** Built using modern CSS Grid auto-fit properties that perfectly transform from desktop monitors down to compact mobile phone screens.
* **Text Wrapping Protection:** Implements strict `overflow-wrap` and `word-wrap` mechanics ensuring that multi-line text options never push past button boundaries or distort layout cards on small touchscreens.
* **Aspect Ratio Defenses:** Utilizes `flex-shrink: 0` rules to prevent checkboxes and interactive elements from squeezing or distorting when long descriptive text labels press against them.
